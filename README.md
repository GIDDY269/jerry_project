# 🛡️ Amazon/AWS Cybersecurity Metrics Dataset (2014–2024)

This repository contains a curated dataset of cybersecurity metrics related to Amazon and Amazon Web Services (AWS) between 2014 and 2024. The dataset focuses on key indicators of organizational security readiness, training, and operational effectiveness. It is designed for use in cybersecurity research, performance benchmarking, and risk analysis.

---


## 📚 Data Sources

Data was extracted from a combination of:
- Amazon Annual Reports and ESG Disclosures
- AWS Security and Compliance Blog
- AWS GuardDuty / Security Hub documentation
- KnowBe4 Phishing Benchmark Reports
- Wiz, Verizon DBIR, and SANS threat intelligence blogs
- Public phishing case studies involving AWS domains
- flAWS CloudTrail dataset for anomaly detection simulation

Where direct data was unavailable, values were estimated from trusted industry reports and confirmed Amazon statements.

---

## 📊 Use Cases

This dataset is ideal for:
- Analyzing enterprise-level cybersecurity trends
- Training machine learning models on security effectiveness
- Benchmarking Amazon's security maturity over time
- Supporting academic papers or case studies on cloud security

---

## ⚠️ Limitations & Assumptions

- Not all metrics are available for every year between 2014–2024.
- Some values are inferred or normalized from ranges or indirect references.
- No confidential or internal Amazon data is used.
- This dataset is best used for **exploratory, research, or non-commercial purposes**.
